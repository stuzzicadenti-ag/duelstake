# DuelStake

Competitive gaming matchmaking platform where players find opponents, set stakes, and compete for real money across popular titles.

## Features

- **1v1 Duels** - Head-to-head staked matches with custom wager amounts
- **Tournaments** - Bracket-style competitions with entry fees and prize pools
- **Ranked Ladders** - Free XP-based competitive play with seasonal rewards
- **Free Play** - Casual matchmaking for practice and fun
- **6 Featured Games** - FIFA 26, Battlefield 6, Call of Duty, Fortnite, Rocket League, Valorant
- **Leaderboard** - Weekly and all-time rankings with earnings tracking
- **Tiered Pricing** - Free, Pro, and Team plans

## Tech Stack

- **Frontend**: Static HTML + CSS (no frameworks, no dependencies)
- **Hosting**: GitHub Pages
- **CI/CD**: GitHub Actions (automated deployment on push)
- **SEO**: Open Graph, Twitter Cards, structured data (Organization schema)

## Business Model

- **Free tier**: 3 matches/day, leaderboard access
- **Pro tier**: EUR 9.99/mo - unlimited matches, priority matchmaking, stats dashboard
- **Team tier**: EUR 29.99/mo - team management, private tournaments, API access
- **Platform fee**: Small percentage on staked match payouts

## Future Plans

- Backend API (Node.js / Python) for user accounts and matchmaking
- Real-time matchmaking with WebSocket connections
- Payment integration (Stripe) for deposits, withdrawals, and subscriptions
- Anti-cheat system with match result verification
